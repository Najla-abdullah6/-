إعداد البيانات (Data Generation): تم إنشاء جدول يحاكي عمليات شراء يومية تحتوي على التاريخ، المنتج، السعر، والكمية.الهندسة والتحويل (Feature Engineering): حساب عمود إجمالي_المبيعات بضرب السعر في الكمية.التجميع والتحليل (Aggregation): استخدام groupby() لمعرفة أي المنتجات والفئات تحقق أعلى مبيعات.التصور المالي والبياني (Data Visualization): رسم مخطط شريطي مقارن بين المنتجات ومخطط دائري يوضح الحصة السوقية لكل فئة.
